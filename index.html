01About me

ResearchModeling

Market making on a prediction-market order book

Implementing and calibrating a quoting model for Polymarket's order book, starting with traditional sports markets. It is an Avellaneda–Stoikov-style framework adapted to a binary payoff, working in logit space. With about $100 of capital the dollar PnL is noise by design, so the deliverable is the model, its calibration against live data and the risk controls.

  • Where equity analogies break: jumps near resolution and bounded prices change the inventory and quoting math.
  • Scoping from data: esports were excluded after live data showed prices moving roughly 10–30× faster per minute than baseball markets, so the reaction parameters did not transfer.
  • Earlier result: an event study of public figures' posts against market prices found no capturable signal; it was closed and kept as a reference.
  • Hard rules: a backtest on a resolved market before risking capital; no live order without explicit confirmation.

Shows: stochastic modeling, calibration on real data, risk limits, a dated decision log.

Python · Stochastic control · Backtesting · pytest · CLOB API

Customer-service automation and CRM for a used-vehicle dealership

End-to-end system for a small dealership: an LLM-powered WhatsApp assistant that answers questions from live inventory, a private admin CRM, a public inventory website and an Instagram agent. Whatever the assistant cannot resolve is escalated to the owner.

  • Assistant: Meta webhook, FastAPI, Claude with tool use (inventory search, spec lookup, vehicle history report, photos, escalation). Specs come from search, not model memory.
  • Data: PostgreSQL with inventory, leads and conversations; hourly inventory sync from a spreadsheet; weekly snapshots of US and local market prices to compute resale margins.
  • Scheduled work: follow-ups after 24 h, 72 h and 7 days of silence, appointment reminders.
  • Surfaces: React admin CRM over a private VPN, Next.js public website with financing calculator, SEO and analytics.
  • Media: FFmpeg and Whisper for automatic video editing and captions. Instagram agent for comment moderation and DMs.
  • Guardrails: message de-duplication, spam and vendor detection, image understanding for documents, owner escalation.

Shows: LLM tool use in production, data modeling in SQL, scheduled pipelines, deployment and monitoring.

Python · FastAPI · PostgreSQL · Docker · Claude API · WhatsApp Business · React · Next.js · FFmpeg · Whisper

05How I work

Skeptical by default

A suspiciously good backtest is a methodology bug until proven otherwise: look-ahead, overfitting, fees, slippage.

Assumptions stated

Every number comes with its data, window and conditions, and what would break it.

Tests where it matters

Math, fee calculations and anything that touches money get tests before they count as done.

Humans in the loop

Automation answers what it can verify and escalates the rest. Nothing irreversible runs unconfirmed.
